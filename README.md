# Rsbuild project

## Demo

https://github.com/IElecec/web_ui/raw/master/demo.mp4

## Setup

Install the dependencies:

```bash
pnpm install
```

## Get started

Start the dev server:

```bash
pnpm dev
```

Build the app for production:

```bash
pnpm build
```

Preview the production build locally:

```bash
pnpm preview
```
